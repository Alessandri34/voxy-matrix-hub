  • Time Delay : Signature du premier contrat post-IA dans les jours qui suivent l'activation et le coaching mental.
  • Effort & Sacrifice : Plus aucune saisie manuelle de données, le CRM se remplit tout seul et le commercial est guidé par l'analyse.

ÉTAPE 9 : Routage CRM & Alerting "Push"

Durée: 1h00
Valide : SKILL OUTBOUND-8

Actions Directives :

  1. Architecture de la Pipeline Sales : Connectez l'API de Pipedrive (ou GoHighLevel). Paramétrez un "Stage" dédié nommé "🔥 Lead Sécurisé par IA". Exigez que ce canal soit sanctuarisé (aucune entrée manuelle humaine autorisée).
  2. Webhooks Sortants (Vapi -> CRM) : Paramétrez l'évènement "End of Call" dans le système vocal. Extrayez le JSON contenant le "Call Summary" et dispatchez-le vers les champs personnalisés créés dans le CRM (Notes de qualification, Budget, Intérêt).
  3. Notification Instantanée (Make.com) : Construisez le pont d'alerte : Vapi API -> Make.com -> Slack/Discord/App. Configurez des filtres (Router Make) pour que seules les fiches ayant passé le "BANT" déclenchent le son d'alerte sur le smartphone du client.
  4. Simulation & Ancrage Psychologique : Déclenchez une attaque de webhook factice (Postman) en direct lors de la visio.
    Langage commun : "Entendez-vous ce son ? C'est le bruit d'une opportunité financière qualifiée par une machine alors que vous étiez occupé. C'est ça, le vrai levier."

ÉTAPE 10 : Data Analytics & "Score Serenity"

Durée: 1h00
Valide : SKILL OUTBOUND-9

Actions Directives :

  • Désossage du Transcript (NLP) : Affichez un compte-rendu JSON post-appel réel. Formez le client à ignorer l'onglet basique "Transcription littérale" pour exploiter le "Structured Data" (points de blocage extraits automatiquement, budget implicitement avoué).
  • Algorithme "Score Serenity" : L'IA utilise le prompt interne Evaluator pour noter le prospect de 1 à 100 sur un triptyque : Axe d'Urgence, Axe Financier (Autorité), et Axe de Résistance psychologique.
  • Calibration "Cinq Minutes Chrono" : Enseignez la routine de l'Élite avant la visio.
    Directive Absolue : Forcez le client à utiliser cette arme d'ingénierie sociale. S'il découvre dans la fiche générée que la frustration du "manque de temps" est à 90/100, la première phrase du Zoom devra être : "Vous m'avez semblé être quelqu'un dont le temps est précieux, allons à l'essentiel." Effet magique d'alignement immédiat.

ÉTAPE 11 : Transition Symbiotique & Neuro-Closing

Durée: 2h00
Masterclass Transversale

Actions Directives :

  • Le "Hand-Off" Magistral : Transmettez l'architecture verbale d'introduction de closing (Vente High-Ticket). Le commercial ne doit jamais avouer "mon robot vous a appelé hier". Il assoit son autorité par stature : "J'ai pris connaissance de l'excellent compte rendu rédigé par mon assistant stratégique de présélection, et il semblerait que le goulot d'étranglement soit X..."
  • Jeu de Rôle Clinique ("Shadowing" Objections) : Allouez 45 min pour frapper le client avec de fausses objections pures ("C'est trop cher", "Il faut que j'en parle à mon associé", "On a déjà une agence"). Le formateur corrige le langage corporel, le ton, et la boucle de rétention.
  • Passation Média & Gouvernance : Remettez solennellement les "Clés du Château" (Logins d'Architectures Make, Admin Vapi Central, Dashboards). Formez-le sur les killswitches (boutons d'arrêt d'urgence IA). Clôturez l'accompagnement d'excellence.
